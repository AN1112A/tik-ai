🤖 Tikkurila Chatbot - AI-Powered Integration

This example shows how to integrate the chatbot with OpenAI or Anthropic for intelligent, conversational responses.

🆚 Rule-Based vs AI-Powered

📋 Rule-Based (No API Key)

  • ✅ Instant setup
  • ✅ No ongoing costs
  • ✅ Predictable responses
  • ✅ Privacy-focused
  • ⚠️ Less flexible
  • ⚠️ Template-based answers

🤖 AI-Powered (With API Key)

  • ✅ Natural conversations
  • ✅ Contextual understanding
  • ✅ Handles complex queries
  • ✅ Follow-up questions
  • 💰 ~$0.001-0.003 per chat
  • 🔑 Requires API key

📝 OpenAI Integration

Add AI-powered responses with just your OpenAI API key:

<script type="module">
  import { TikkurilaChatbot } from './src/chatbot-widget.js';
  
  const chatbot = new TikkurilaChatbot({
    baseUrl: window.location.origin,
    
    // AI Configuration
    apiKey: 'sk-...', // Your OpenAI API key
    apiProvider: 'openai',
    model: 'gpt-4o-mini', // Fast and affordable
    
    // Optional: Appearance
    primaryColor: '#0066cc',
    greeting: 'Hi! I\'m your AI decorating assistant.'
  });
  
  await chatbot.init();
  window.tikkurilaChatbot = chatbot;
</script>

🔑 Getting an OpenAI API Key

  1. Go to platform.openai.com
  2. Sign up or log in
  3. Navigate to API Keys
  4. Click Create new secret key
  5. Copy the key (starts with sk-)
  6. Add billing information (pay-as-you-go)
💰 Cost Estimate: With GPT-4o-mini, each conversation costs approximately $0.001-0.003. That means you can handle 300-1000 customer conversations for just $1!

🎭 Anthropic (Claude) Alternative

Prefer Claude? Use Anthropic instead:

const chatbot = new TikkurilaChatbot({
  baseUrl: window.location.origin,
  
  // Anthropic Configuration
  apiKey: 'sk-ant-...', // Your Anthropic API key
  apiProvider: 'anthropic',
  model: 'claude-3-haiku-20240307', // Fast and affordable
  
  primaryColor: '#0066cc'
});

🎨 Model Recommendations

OpenAI Models:

  • gpt-4o-mini (recommended) - Fast, affordable, excellent quality
  • gpt-4o - More capable but more expensive
  • gpt-3.5-turbo - Budget option, good for simple queries

Anthropic Models:

  • claude-3-haiku-20240307 (recommended) - Fast and cost-effective
  • claude-3-sonnet-20240229 - Balanced performance and cost
  • claude-3-opus-20240229 - Most capable, higher cost

🎯 What the AI Knows

The AI is trained with your knowledge base including:

  • ✅ All product information (features, uses, links)
  • ✅ FAQs and common questions
  • ✅ Routing rules (e.g., "bathrooms → Luja")
  • ✅ Conversation history and context
  • ✅ Customer requirements (rooms, surfaces, issues)

🔒 Security & Privacy

Important:
  • API keys are used client-side (visible in page source)
  • For production, consider using a backend proxy to hide keys
  • Set usage limits in OpenAI/Anthropic dashboard
  • Monitor API usage regularly
  • Conversations are sent to AI provider (see their privacy policy)

🛡️ Production Best Practice

For production deployments, use a backend proxy:

// Backend proxy endpoint
const chatbot = new TikkurilaChatbot({
  baseUrl: window.location.origin,
  apiEndpoint: '/api/chat', // Your backend endpoint
  // No API key in frontend!
});

Then implement /api/chat on your backend to:

  1. Receive chat messages from frontend
  2. Add API key securely on server
  3. Forward to OpenAI/Anthropic
  4. Return response to frontend
  5. Optional: Log, rate-limit, filter content
