🎨 Tikkurila Chatbot - Basic Integration Example

This page demonstrates the simplest way to add the Tikkurila chatbot to your website.

📝 The Code

All you need is these few lines before your closing </body> tag:

<!-- Tikkurila Chatbot -->
<script type="module">
  import { TikkurilaChatbot } from './src/chatbot-widget.js';
  
  const chatbot = new TikkurilaChatbot({
    baseUrl: window.location.origin,
    primaryColor: '#0066cc',
    greeting: 'Hi! How can I help with your decorating project?'
  });
  
  await chatbot.init();
  window.tikkurilaChatbot = chatbot;
</script>

💡 How It Works

  1. Import the chatbot widget - ES6 module with all functionality
  2. Configure options - Set your brand colors, position, greeting, etc.
  3. Initialize - Loads the knowledge base and creates the UI
  4. Done! - The chatbot is ready to help your customers

🎨 Customization Options

const chatbot = new TikkurilaChatbot({
  // Required
  baseUrl: 'https://your-domain.com',
  
  // Optional - AI Configuration
  apiKey: 'sk-...', // OpenAI or Anthropic key
  apiProvider: 'openai', // or 'anthropic'
  model: 'gpt-4o-mini',
  
  // Optional - Appearance
  primaryColor: '#0066cc',
  accentColor: '#004999',
  position: 'bottom-right', // or 'bottom-left'
  
  // Optional - Content
  greeting: 'Custom greeting message'
});

🔄 Programmatic Control

You can control the chatbot with JavaScript:

// Open the chat
tikkurilaChatbot.open();

// Close the chat
tikkurilaChatbot.close();

// Toggle (open if closed, close if open)
tikkurilaChatbot.toggle();

// Send a message programmatically
tikkurilaChatbot.sendMessage('Your message here');

// Destroy the chatbot
tikkurilaChatbot.destroy();
