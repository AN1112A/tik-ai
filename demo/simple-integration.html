🎨 Tikkurila Decorating Assistant

This page demonstrates how easy it is to integrate the Tikkurila Decorating Assistant into any website.

Integration Code

To add the assistant to your website, simply include this script tag:

<script type="module">
  import { TikkurilaChatInterface } from './src/chat-interface.mjs';
  import { KB } from './src/kb-loader.mjs';
  
  // Initialize the assistant
  const container = document.createElement('div');
  document.body.appendChild(container);
  
  const kb = new KB(window.location.origin);
  const assistant = new TikkurilaChatInterface(container, {
    baseUrl: window.location.origin,
    primaryColor: '#1e40af',
    accentColor: '#3b82f6'
  });
</script>
