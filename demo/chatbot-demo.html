Easy Integration

Add the Tikkurila Decorating Assistant to your website in minutes

<!-- Add to your HTML -->
<script src="https://your-domain.github.io/your-repo/embed.js"></script>
<script>
  TikkurilaChat.init({
    // Optional: Add your OpenAI API key for AI-powered responses
    apiKey: 'your-api-key-here',
    apiProvider: 'openai', // or 'anthropic'
    
    // Customize appearance
    primaryColor: '#0066cc',
    position: 'bottom-right',
    greeting: 'Hi! How can I help with your decorating project?'
  });
</script>

Without an API key, the assistant uses rule-based matching from the knowledge base. With an API key, it provides AI-powered conversational responses.

Programmatic Control

// Open the chat
TikkurilaChat.open();

// Close the chat
TikkurilaChat.close();

// Send a message programmatically
TikkurilaChat.sendMessage('What paint should I use for my bathroom?');
