🎨 Tikkurila Chatbot - Custom Styling

Learn how to customize the chatbot's appearance to match your brand perfectly.

🎨 Color Customization

The easiest way to customize is through the configuration:

const chatbot = new TikkurilaChatbot({
  baseUrl: window.location.origin,
  
  // Brand Colors
  primaryColor: '#667eea', // Main color for buttons, header
  accentColor: '#764ba2', // Hover states, gradients
  
  // Position
  position: 'bottom-right' // or 'bottom-left'
});

🔧 Advanced CSS Customization

For complete control, override CSS custom properties:

<style>
  .tikkurila-chatbot-container {
    /* Colors */
    --primary-color: #667eea;
    --accent-color: #764ba2;
    
    /* Dimensions */
    --border-radius: 16px;
    --shadow: 0 8px 40px rgba(0, 0, 0, 0.2);
    
    /* Animation speed */
    transition-duration: 0.5s;
  }
  
  /* Customize chat button */
  .tikkurila-chat-button {
    width: 70px;
    height: 70px;
  }
  
  /* Customize chat window size */
  .tikkurila-chat-window {
    width: 420px;
    height: 650px;
  }
  
  /* Customize message bubbles */
  .message-bot .message-content {
    background: linear-gradient(135deg, #667eea, #764ba2);
    color: white;
  }
  
  /* Customize header */
  .tikkurila-chat-header {
    background: linear-gradient(135deg, #667eea, #764ba2);
  }
</style>

📏 Size Customization

Adjust the chatbot's dimensions:

<style>
  /* Larger chat button */
  .tikkurila-chat-button {
    width: 80px;
    height: 80px;
  }
  
  /* Wider chat window */
  .tikkurila-chat-window {
    width: 450px;
  }
  
  /* Taller chat window */
  .tikkurila-chat-window {
    height: 700px;
  }
  
  /* Full-height on mobile */
  @media (max-width: 768px) {
    .tikkurila-chat-window {
      height: 100vh;
      width: 100vw;
    }
  }
</style>

✨ Animation Customization

Customize animations and transitions:

<style>
  /* Slower animations */
  .tikkurila-chat-window {
    transition: all 0.5s cubic-bezier(0.4, 0, 0.2, 1);
  }
  
  /* Faster button hover */
  .tikkurila-chat-button {
    transition: transform 0.2s ease;
  }
  
  /* Custom message animation */
  @keyframes messageSlide {
    from {
      opacity: 0;
      transform: translateX(-20px);
    }
    to {
      opacity: 1;
      transform: translateX(0);
    }
  }
</style>

🎯 Font Customization

Use your brand's font:

<style>
  .tikkurila-chatbot-container {
    font-family: 'Your Brand Font', -apple-system, sans-serif;
  }
  
  /* Larger font size */
  .message-content {
    font-size: 15px;
  }
  
  /* Custom header font */
  .tikkurila-chat-header h3 {
    font-family: 'Your Display Font', serif;
    font-size: 18px;
  }
</style>

📱 Responsive Design

The chatbot is responsive by default, but you can customize mobile behavior:

<style>
  @media (max-width: 768px) {
    /* Full-screen on mobile */
    .tikkurila-chat-window {
      width: 100vw;
      height: 100vh;
      bottom: 0;
      border-radius: 0;
    }
    
    /* Hide chat button on very small screens */
    @media (max-width: 380px) {
      .tikkurila-chat-button {
        width: 50px;
        height: 50px;
      }
    }
  }
</style>

🎨 Position Customization

Place the chatbot anywhere:

// Configuration option
const chatbot = new TikkurilaChatbot({
  position: 'bottom-left' // or 'bottom-right'
});

// Or with CSS
.tikkurila-chatbot-container {
  left: 20px;  /* instead of right */
  bottom: 20px;
}

// Top-right corner
.tikkurila-chatbot-container {
  top: 20px;
  right: 20px;
  bottom: auto;
}
