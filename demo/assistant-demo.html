Integration Examples

Basic Integration

Add the assistant to your website with a single script tag:

<script src="https://your-domain.com/src/embed.mjs"></script>

Custom Configuration

Customize the assistant with your own settings:

<script src="https://your-domain.com/src/embed.mjs"
        data-base-url="https://your-domain.com"
        data-primary-color="#1e40af"
        data-position="bottom-left"></script>

Programmatic Control

Control the assistant with JavaScript:

// Initialize
const assistant = await TikkurilaAssistant.init({
  baseUrl: 'https://your-domain.com',
  primaryColor: '#1e40af'
});

// Control
assistant.open();
assistant.close();
assistant.reset();

Multiple Instances

Create multiple assistants for different sections:

// Interior paint assistant
const interior = await TikkurilaAssistant.init({
  theme: 'interior'
});

// Exterior paint assistant  
const exterior = await TikkurilaAssistant.init({
  theme: 'exterior'
});

Configuration Options

{
  "baseUrl": "https://your-domain.com",     // Base URL for API calls
  "theme": "light",                         // light | dark
  "position": "bottom-right",               // bottom-right | bottom-left | top-right | top-left
  "primaryColor": "#1e40af",               // Primary brand color
  "accentColor": "#3b82f6",                // Accent color
  "autoLoad": true,                        // Auto-initialize on page load
  "debug": false                           // Enable debug logging
}

API Reference

// Initialize assistant
TikkurilaAssistant.init(options)

// Get instance
TikkurilaAssistant.getInstance(id)

// Destroy instance
TikkurilaAssistant.destroy(id)

// Destroy all instances
TikkurilaAssistant.destroyAll()

// Instance methods
assistant.open()        // Open chat
assistant.close()       // Close chat
assistant.reset()       // Reset conversation
