🛠️ Integration Guide

To integrate this AI assistant into your website, simply add the following code:

<!-- Add this to your HTML --> <div id="tikkurila-assistant" data-tikkurila-assistant data-theme="light" data-position="bottom-right"></div> <!-- Include the scripts --> <script src="src/kb-loader.mjs" type="module"></script> <script src="src/ai-assistant.js"></script> <script src="src/embeddable-assistant.js"></script>

Configuration Options:

  • data-theme: "light" or "dark"
  • data-position: "bottom-right", "bottom-left", "top-right", "top-left"
  • data-api-key: Your OpenAI API key (optional, for enhanced AI responses)
  • data-base-url: Base URL for the knowledge base (defaults to current domain)
